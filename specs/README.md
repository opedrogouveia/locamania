# specs/

Uma spec por funcionalidade **nova**, escrita antes de implementar: objetivo, escopo (incluído × fora),
regras de negócio, API (método/rota/quem), permissões, auditoria e **critérios de aceitação** em
checklist.

O MVP inteiro foi especificado pela própria cliente em [`../docs/REQUISITOS_CLIENTE.txt`](../docs/REQUISITOS_CLIENTE.txt)
(47 seções) e detalhado em [`../docs/PLANO_MVP.md`](../docs/PLANO_MVP.md) (modelo de domínio, regras,
telas e o critério de pronto §7). As próximas funcionalidades pedidas depois do MVP ganham arquivo
aqui (ex.: `specs/web-push.md`, `specs/gateway-asaas.md`).
