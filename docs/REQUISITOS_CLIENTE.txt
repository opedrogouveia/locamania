LOCAMANIA — SISTEMA DE LOCAÇÃO DE MOTOS

1. OBJETIVO DO SISTEMA

Criar um sistema completo para uma empresa de aluguel de motos, chamado Locamania.

O sistema deverá funcionar em:

* 💻 Computador — sistema administrativo da Locamania.
* 📱 Celular — aplicativo exclusivo para os clientes.
* ☁️ Banco de dados online — compartilhado entre os dois.

O objetivo é centralizar toda a operação da locadora: cadastro de clientes, cadastro das motos, contratos, pagamentos, vencimentos, manutenção, documentos, notificações, situação das motos e acompanhamento dos aluguéis.

O sistema deve ser simples de utilizar, mas completo para a administração.

⸻

2. SISTEMA PARA COMPUTADOR — ADMINISTRATIVO

Este será o sistema principal utilizado pela proprietária/administradora da Locamania.

O administrador deverá conseguir visualizar e controlar praticamente toda a operação pelo computador.

“Sem conexão com a internet.”

O desenvolvedor poderá escolher a tecnologia mais adequada, desde que cumpra os requisitos.

É importante que:

* O sistema administrativo funcione muito bem em computador.
* O aplicativo funcione em Android e iPhone.
* Os dados sejam centralizados.
* A API seja segura.
* O sistema seja escalável.
* O banco tenha backup.
* O aplicativo possa receber atualizações sem perder dados.

Preferencialmente, desenvolver o aplicativo mobile de maneira que seja possível manter uma única base de código para Android e iOS, reduzindo custos de manutenção.

Quero que o sistema permita administrar a Locamania praticamente inteira pelo computador.

1. Cadastrar o cliente.
2. Cadastrar/selecionar a moto.
3. Criar o contrato.
4. Definir o valor e vencimento.
5. Registrar o pagamento/cobrança.
6. Entregar a moto.
7. Acompanhar os pagamentos.
8. Receber alertas de atraso.
9. Acompanhar manutenção.
10. Receber alertas de manutenção.
11. Acompanhar documentos.
12. Controlar a situação de cada moto.
13. Consultar todo o histórico.
14. Encerrar o aluguel quando necessário.

Enquanto isso, o cliente deverá ter no celular somente aquilo que precisa para acompanhar seu próprio aluguel:

Minha moto + meu contrato + meus pagamentos + minhas manutenções + meus avisos + meu suporte.

O objetivo é que a Locamania tenha um sistema centralizado, profissional e automatizado, evitando depender de planilhas, papéis ou controles separados.
